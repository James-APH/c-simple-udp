# Simple UDP

I made this project as a test, for a guide to socket programming I am making in.
The main idea was to get a server to receive a message from a client.

## Build Instructions

To make the Client Executable use the following make command:

```sh
make client
```

To make the Server Executable use the following make command:

```sh
make server
```

To make both Executables, use the following make command:

```sh
make all
```

And to clean up the project folder use the following make command:

```sh
make clean
```

## Run Instructions

In one terminal run the server with: `./server`, then in another terminal run
`./client`
